# Brand asset

`rudra-creative-logo.png` is the canonical supplied Rudra Creative logo for this repository. It is used by the storefront and admin application as the displayed logo and favicon. Keep the original proportions; do not recolor or redraw without the owner's approval.

To update the mark, replace this file with the owner-approved PNG of the same filename, or update both application imports if the approved canonical filename changes. Rebuild both frontends after replacing the asset. A separate mobile mark or vector asset may be added later if supplied and approved by the owner.
